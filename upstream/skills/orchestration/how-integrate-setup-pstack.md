# Setup integration policy

Preserve discovery, current-state loading, reasoning-budget selection, a concrete proposal, validation before saving, and read-back verification. Do not replace unavailable model/provider choices or shrink panels. Map an abstract budget to the highest supported same-model effort at or below target and show the rounding in the existing full proposal; exact unsupported task options remain a choice. Saved effort is a starting preference for the job-adjustment policy, not a fixed dispatch command.

Replace Cursor rules with [shared Codex/Opus defaults](../../../models.md) and a user-owned plain Markdown file at the XDG path defined there. The agent interprets preferences; no runtime JSON parser or copied model catalog is added. Workflows read preferences when invoked, so setup installs no session hook. Setup uses its own catalog/validation/write instructions, not the how/why investigation adapter and its source-edit prohibition. Follow the host's management rules before editing an existing managed configuration.

Both verification creation/maintenance pairs are now adopted. Retain the two original optional offers, and on acceptance read the companion from this distribution rather than an installed namesake. No verification workflow is started merely by configuring models.

Synthetic catalog evaluations covered saving all roles, a changed budget, explicit inheritance, idempotent reruns, and preserving an existing file when a required provider was unavailable. They did not invoke providers or modify personal configuration. See the [evaluation prompts](../../../evals/setup-pstack.md) and [verification record](../../../docs/verification.md).

For A-to-B updates, review role inventory, option/budget interpretation, persistence, and optional offers together. Keep optional offers aligned with the adopted dependency set. Keep the configured defaults and explicit failure behavior unless a reviewed user decision changes them.

The shared [model policy](how-integrate-model-policy.md) traces per-job effort and speed to the original Subagents instructions and records the user-approved starting-level interpretation.
