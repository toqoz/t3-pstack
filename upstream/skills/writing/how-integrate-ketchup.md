# Catch-up adoption

Ketchup is adopted with only the `/visualize` command replaced by available host visualization tools. Ketchup-video is copied unchanged and retains its ketchup companion. No new dependency, Patch, or Design change is introduced.

The source and license are recorded in [the upstream guide](../../README.md). Both source directories contain only SKILL.md. Ketchup-video prescribes output and inspection standards, not a bundled renderer or fixed executable. Tool availability is checked when invoked; an actual rendering failure retains the original failure report and action-item fallback.

Preserve the user's-message window, read-only catch-up, complete pending calls, existing-media use, evidence honesty, video subtitles and measured holds, and explicit unfinished work. Host rules continue to govern running-agent observation and visual display; this does not authorize polling delegates or inventing screenshots.

Artifact checks verify the two exact visualization replacements, unchanged video source, companion closure, and provenance. No live catch-up, movie rendering, frame inspection, or media playback is claimed by adoption.
