### Worktree and simulator cleanup

1. Snapshot and audit. Record `df -h /` and collect worktree paths from `git worktree list --porcelain`, then inspect size, age, actual merge base, dirty state, remote/PR state, and authorized T3 activity. Resolve the actual default/PR base branch. The bundled worktree-audit script scans Cursor transcripts and is not a T3 usage collector; do not run it for this pass. Unknown usage or incomplete history is not proof a worktree is unused.

2. The collected metadata is evidence, not permission. The pinned and active chats are the real artifact (principle-prove-it-works). Get that set from the user or sidebar and cross-check every candidate. A merge/clean result does not establish that a worktree is unused; the pinned set wins.
3. Verify usage before deleting. For every worktree whose recent usage is unresolved, or anything you doubt, fan subagents out to read authorized completed-thread activity and report whether the chat is pinned or ongoing, without polling running delegates and which worktrees it touches (principle-guard-the-context-window, transcripts are bulk). A pinned chat spawns arena and repro trees into sibling worktrees via background subagents, and those are in use even when their names never hit the sidebar. Pick each subagent's reasoning level and fast or standard speed for the job, per the Subagents section.
4. Pause on irreversible loss. For tracked uncommitted edits, show the diff and get a decision first, since removing a clean worktree is recoverable from its branch but uncommitted work is gone. Identify untracked throwaway files by name before dropping that scratch state. Per Autonomy, clean and merged and not-in-use proceeds. Tracked uncommitted work and in-use worktrees pause.
5. Prune the confirmed set. Per path, `git worktree remove --force <path>`. If the dir survives on ignored build artifacts, `rm -rf` it, then `git worktree prune`. Branch refs survive, so no commits are lost. Confirm with `df -h /` and re-list.
6. Simulators and other reclaimers. Simulators are usually the next-biggest win. `xcrun simctl --set testing delete all` (XCTestDevices clones), `xcrun simctl delete unavailable`, and `xcrun simctl runtime list` then `runtime delete <id>` for old runtimes. More when needed: Xcode `DerivedData` and `iOS DeviceSupport`, `~/Library/Application Support/Cursor` (`state.vscdb.backup`, and `snapshots/roots/<root>` where a `<root>` named for a folder you opened as a workspace balloons), package caches (pnpm, uv, brew, yarn). Clear only caches the user has not said to keep.

This is the one playbook that deletes user state with no code review to catch a slip, so the gates above are the review.

**Reply:** `df -h /` before and after with space reclaimed, the worktrees pruned, and a one-line reason for each held back (in-use by which chat, or uncommitted work).
